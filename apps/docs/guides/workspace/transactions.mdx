The **Transactions** page is for support leads, finance staff and admins who want payments and orders next to the customers and conversations they belong to. Entries are added by hand or arrive automatically from your own systems through signed webhooks.

**Role needed:** agent, admin or owner to view, add, edit and export. Only admins and owners can delete a transaction or manage webhook endpoints. Viewers do not see this page.

## Open the page

Open **Transactions** in the left menu, under **Operations**. At the top, two figures summarize whatever you are currently looking at: **Matching transactions** (the count) and **Completed total** (the sum of completed transactions, shown per currency when more than one currency is present). The totals cover the whole filtered set, not only the rows loaded on screen.

The table lists **Date**, **Description**, **Contact**, **Source**, **Status** and the amount. **Source** is either **Manual** (entered by a person) or **Webhook** (sent by another system). **Status** is **Pending**, **Completed**, **Failed** or **Refunded**. Refunds are shown as negative amounts. Click **Load more** at the bottom for older entries.

## Filter and search

<Steps>
  <Step title="Search">
    Type in **Search description or external ID**.
  </Step>
  <Step title="Narrow down">
    Pick a **Status** and a **Source**, and set **From** and **To** dates. The dates apply to when the transaction occurred.
  </Step>
  <Step title="Read the totals">
    The summary at the top updates as you change filters.
  </Step>
</Steps>

## Add a transaction

Click **Add transaction**. Enter the **Amount** (use a negative number for a refund), the **Currency** as a 3-letter code such as USD, a **Status**, a **Description** and, optionally, an **External ID** (for example your order number). Click **Add**. Using the same External ID twice for manual entries is refused.

## Open and edit a transaction

Click a description to open the **Transaction** panel. It shows the date, source, external ID and contact. You can change the **Status** and **Description**, then click **Save**. Admins and owners also see **Delete**, which cannot be undone.

## Export to CSV

Click **Export CSV**. Yulona prepares a file named `transactions.csv` that contains every transaction matching your current filters (not only the visible page) and your browser downloads it. Cells that start with `=`, `+`, `-` or `@` are prefixed with an apostrophe so spreadsheet programs do not run them as formulas. Each export is recorded in the [audit log](/guides/account/privacy-and-data).

## Receive transactions from other systems

Admins and owners can click **Webhook endpoints** to let a payment or order system post transactions automatically.

<Steps>
  <Step title="Create an endpoint">
    Enter a **New endpoint name** and click **Create**. The endpoint's URL and a secret appear once.
  </Step>
  <Step title="Save the secret">
    Copy the secret with **Copy secret** and store it safely, then click **I saved it**. It cannot be shown again. If you lose it, use **Rotate secret** to get a new one; the old one stops working immediately.
  </Step>
  <Step title="Give the URL and secret to your developer">
    Your developer sends signed JSON to the URL. The dialog explains how to sign each request with the secret (an HMAC-SHA256 signature plus a timestamp header).
  </Step>
</Steps>

Each endpoint has an on and off switch and a delete button. Deleting an endpoint makes the sender receive errors. Sending the same External ID again updates the existing transaction instead of creating a duplicate.

<Note>
Webhook endpoints need an encryption key on the server. On a self-hosted installation, if endpoint creation fails with a "service unavailable" error, ask your administrator to set `ENCRYPTION_KEY`.
</Note>

## What you should see

New entries appear at the top (newest first by date), and the **Completed total** changes only for transactions with the status **Completed**.

## Common problems

| Symptom | Fix |
|---|---|
| The totals look lower than expected | Only **Completed** transactions count towards the total. |
| "Add" is disabled | **Amount** and **Currency** (3 letters) are required. |
| Your system gets 401 errors | The secret is wrong, the endpoint is off or deleted, or the clock on the sender is more than 5 minutes off. |
