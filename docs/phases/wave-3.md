In selfhosted mode: one tenant, no billing, no super-admin routes unless enabled.

5. Load test script (bun + built-in fetch or `autocannon` via bunx) for widget conversation start/send and API read paths with documented results on this machine; CI updated (lint/typecheck/test/audit/docker build of all images incl. widget). `bun audit` run and findings reported.

Actually run the stack: build all images, bring up prod compose in a scratch project dir (mounts must be from outside `~/Documents` on this Mac — copy deploy assets to the scratchpad), run setup flow against it, hit `/readyz`, register, create widget, start a widget conversation with mock AI provider, verify worker processed it. ## qa-security (the gate)
1. **Cross-tenant sweep over every endpoint**: enumerate routes from `docs/openapi.json` (regenerate via `apps/api/scripts/export-openapi.ts`) plus Hono route table; for each authenticated route with an id/param, prove tenant B cannot read/modify tenant A's resource (403/404) and that unauthenticated requests get 401; fail the test if a route is neither covered nor explicitly allow-listed with a reason. Also RLS-level: every table with `tenant_id` has RLS enabled+forced (query `pg_class`/`pg_policies`) and `yulona_app` has no BYPASSRLS.
2. Security review + fixes: impersonation token revocation (jti denylist checked on every request; `end` endpoint revokes) in range 0800; stored-XSS/markdown handling of message content in dashboard (verify no `dangerouslySetInnerHTML`), CSRF on cookie endpoints, rate limits on public endpoints, upload checks, secrets never in logs (grep + test), webhook/URL SSRF tests, `.strict()` on all bodies (static test), dependency audit (`bun audit`) — fix or document. Move the encryption helper used by worker/api/ops into `packages/crypto` (update importers minimally).
3. End-to-end test (bun test, `tests/e2e`, real Postgres, mock providers): register → create agent + knowledge text → widget config → public widget conversation → AI answers from KB → low-confidence question ⇒ handoff `pending_human` → human takeover reply visible via SSE → return to AI. Plus a Playwright smoke (login + inbox render against the mock/real API) if Playwright installs cleanly; otherwise skip with a note.
4. Final gate report: pass/fail matrix per PLAN DoD §7 items per feature area, listing known gaps honestly.
