2. **Rates and credits.** `llm_model_rates(model, input_credits_per_1k, output_credits_per_1k, enabled)` with a `*` default (platform-wide, readable by the app role, written only via `sa_set_model_rate`); credits as integer micro-credits (1 credit = 1_000_000 micro; rates stored as micro-credits per 1k tokens). `tenant_credits(tenant_id, period, allowance_micro, used_micro, topup_micro)`; SQL `consume_credits(tenant, micro)` drawing monthly allowance first then top-up, atomic (concurrency test). Monthly allowance from `plan_limits` metric `llm_credits_monthly` (widen the CHECK; seed placeholders: free 50 credits, pro 1500, enterprise/self_hosted unlimited) with the period reset handled in `apps/worker/src/billing.ts`. `credit_packs(id, name, credits, price_cents, active)` (admin-managed, seed 3 placeholder packs).
3. **Provider config, any OpenAI-compatible service.** Extend `OpenAiOptions`/`post()` in `packages/providers/src/openai.ts`: `authHeader` (default `Authorization`), `authScheme` (`bearer|raw|none`), `extraHeaders`, `queryParams` (e.g. Azure `api-version`), `chatPath`. Replace the global `portsFromProviders(createProvidersFromEnv())` in `apps/worker/src/jobs/index.ts` and `apps/api/src/routes/knowledge.ts` with an `LlmResolver` dependency (per call). Validate profile base URLs with the SSRF helper (private hosts allowed only in selfhosted). In SaaS the agent's `model` must be an enabled model (else fall back to the profile default and say so in the sandbox result).
4. **Enforcement + top-ups.** Gate at the top of `handleInboundMessage` and in the sandbox: SaaS and remaining (allowance + top-up) <= 0 => do not call the model; raise a `system_failure` handoff with reason `ai_credits_exhausted`, send a customer-safe notice (configurable text), one admin notification per period (`ops_notify`).
